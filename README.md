## detalhes importantes

- C++ é *case-sensitive*, ou seja, diferencia letras maiúsculas de minúsculas.
- O compilador ignora a maioria das quebras de linha e espaços em branco.
- `std` é o namespace padrão da biblioteca C++ (*Standard Library*).
- O operador `::` é utilizado para acessar elementos dentro de um namespace.
