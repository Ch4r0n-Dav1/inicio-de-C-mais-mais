## detalhes importantes

- C++ é *case-sensitive*, ou seja, diferencia letras maiúsculas de minúsculas.
- O compilador ignora a maioria das quebras de linha e espaços em branco. Portanto, o código poderia ser escrito em uma única linha.
- `std` é o namespace padrão da biblioteca C++ (*Standard Library*).
- O operador `::` é utilizado para acessar elementos dentro de um namespace.

Por exemplo, o código:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello World!";
    return 0;
}
```

Poderia ser escrito sem o prefixo `std::` utilizando `using namespace std;` antes da função `main()`.
